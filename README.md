# gigalection

Записи лекций → текст → конспект.

Видео лекции расшифровывается локально моделью [GigaAM v3](https://github.com/salute-developers/GigaAM) через [onnx-asr](https://github.com/istupakov/onnx-asr), из видео вынимаются кадры доски/слайдов, а затем [Claude Code](https://claude.com/claude-code) пишет по расшифровке структурный конспект с формулами, глоссарием и вопросами для самопроверки.

Расшифровка работает офлайн на CPU, видеокарта не нужна.

## Как это работает

```
input/Матанализ/Лекция 3.mp4
        │  transcribe.py
        ▼
output/Матанализ/Лекция 3/
    transcript.md      расшифровка с таймкодами [ЧЧ:ММ:СС] и ссылками на кадры
    frames/            кадры доски/слайдов, имя файла = таймкод
        │  Claude Code (правила в CLAUDE.md)
        ▼
    конспект.md        конспект: разделы, формулы, дополнения, вопросы и ответы
    конспект.html      то же с формулами KaTeX (render.py), открывать в браузере
output/Матанализ/глоссарий.md   термины предмета, пополняются с каждой лекцией
```

1. **Звук** извлекается ffmpeg (16 кГц, моно), режется на фрагменты по паузам (Silero VAD) и распознаётся GigaAM v3 e2e RNN-T (с пунктуацией и заглавными буквами).
2. **Кадры** сохраняются при смене слайда и не реже раза в 90 секунд, чтобы ловить доску, которую исписывают постепенно.
3. **Конспект** пишет Claude Code по правилам из [CLAUDE.md](CLAUDE.md): разделы с таймкодами, формулы в LaTeX, исправление ошибок распознавания, блоки «💡 Дополнение» со знаниями сверх лекции, термины, 7–12 вопросов с ответами в конце.

## Установка

Нужны **Python 3.10+** и **ffmpeg**.

Windows:

```bash
winget install Gyan.FFmpeg
```

macOS:

```bash
brew install ffmpeg
```

Затем (после установки ffmpeg перезапустите терминал):

```bash
pip install -r requirements.txt
```

При первом запуске модели (~несколько сотен МБ) скачиваются с Hugging Face, дальше всё работает офлайн.

## Использование

1. Положите записи в `input/<Предмет>/` (mp4, mkv, webm, mov, mp3, m4a, wav, …). Файлы прямо в `input/` попадут в предмет «Без предмета».
2. Запустите расшифровку — обрабатываются только новые лекции:

   ```bash
   python transcribe.py
   ```

   На Windows можно просто дважды щёлкнуть `run.bat`.
3. Откройте папку в Claude Code и попросите: «сделай конспект новых лекций».
4. Читайте `конспект.md` в [Obsidian](https://obsidian.md) или `конспект.html` в браузере.

HTML можно пересобрать вручную:

```bash
python render.py
```

### Параметры `transcribe.py`

| Флаг | По умолчанию | Что делает |
|---|---|---|
| `--force` | — | переобработать уже готовые лекции |
| `--no-frames` | — | не извлекать кадры |
| `--frame-every N` | 90 | снимок не реже чем раз в N секунд |
| `--scene X` | 0.12 | порог смены слайда (меньше — больше кадров) |
| `--frame-gap N` | 8 | кадры ближе N секунд схлопываются в один (анимации слайдов) |
| `--para-gap N` | 5 | пауза в секундах, после которой начинается новый абзац |
| `--para-max N` | 90 | максимальная длина абзаца в секундах |
| `--max-seg N` | 20 | максимальная длина фрагмента для распознавания, сек |
| `--no-int8` | — | модель в полной точности вместо int8 (медленнее) |
| `--model NAME` | `gigaam-v3-e2e-rnnt` | любая модель, которую поддерживает onnx-asr |

## Скорость

Лекция 1 ч 36 мин, 1080p, Intel i5-11400F: **~8 минут** на всё (кадры + распознавание), около 12× быстрее реального времени. Сам ASR — около 17×.

## Ограничения

- GigaAM распознаёт русский; термины, фамилии и английские слова могут искажаться. Claude исправляет их по смыслу и по глоссарию, сомнительное помечает `(?)`.
- Условия задач, которые лектор диктует, но не пишет на доске, восстанавливаются по обсуждению — их стоит сверять с задачником.
- `конспект.html` подгружает KaTeX с CDN, для формул нужен интернет.
- Встроенный просмотр Markdown в некоторых приложениях понимает LaTeX не полностью; Obsidian и HTML-версия показывают формулы корректно.
